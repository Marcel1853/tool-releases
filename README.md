# Tool Releases – Downloads

Sammelstelle für die fertigen Versionen meiner Programme – nur Downloads,
kein Quellcode. Jedes Programm hat seine eigene Kennung im Release-Namen,
z. B. `paletten-packschema-v1.6.0`.

## Programme

| Programm | Wofür | Releases |
|---|---|---|
| **Paletten-Packschema** | berechnet und zeigt, wie Pakete auf einer Palette gestapelt werden (Draufsicht, Seitenansicht, 3D, Druck/PDF) | Tags `paletten-packschema-v…` |

## Am einfachsten: Tool Launcher

Der [Tool Launcher](https://github.com/Marcel1853/tool-launcher) installiert,
aktualisiert und startet alle Programme von hier – etwa vom USB-Stick aus,
ohne Anmeldung und ohne Installation. Die Daten der Programme bleiben bei
Updates immer erhalten.

## Von Hand herunterladen

Unter [Releases](https://github.com/Marcel1853/tool-releases/releases) das
gewünschte Programm in der neuesten Version öffnen und die passende Datei
laden:

- **Windows**: `.exe` – Doppelklick genügt, nichts zu installieren.
- **Linux**: `.AppImage` – einmalig als ausführbar markieren
  (Rechtsklick → Eigenschaften → Zugriffsrechte).

Windows kann beim ersten Start warnen („Der Computer wurde durch Windows
geschützt“), weil die Programme nicht signiert sind: „Weitere Informationen“
→ „Trotzdem ausführen“.

## Aktualisieren von Hand

Nur die `.exe` bzw. `.AppImage` gegen die neue austauschen. Der Ordner
`Daten` daneben (gespeicherte Schemas, Einstellungen usw.) bleibt, wie er
ist – nicht löschen.
