# Paletten-Packschema – Downloads

Hier liegen nur die fertigen Versionen des Paletten-Packschemas, kein
Quellcode. Das Programm berechnet und zeigt, wie Pakete auf einer Palette
gestapelt werden (Draufsicht, Seitenansicht, 3D, Druck/PDF).

## Herunterladen

Unter [Releases](https://github.com/Marcel1853/paletten-packer-releases/releases)
die neueste Version öffnen und die passende Datei laden:

- **Windows**: `Paletten-Packschema-<Version>.exe` – Doppelklick genügt,
  nichts zu installieren.
- **Linux**: `Paletten-Packschema-<Version>.AppImage` – einmalig als
  ausführbar markieren (Rechtsklick → Eigenschaften → Zugriffsrechte).

Windows kann beim ersten Start warnen („Der Computer wurde durch Windows
geschützt“), weil das Programm nicht signiert ist: „Weitere Informationen“ →
„Trotzdem ausführen“.

## Aktualisieren

Nur die `.exe` bzw. `.AppImage` gegen die neue austauschen. Der Ordner
`Daten` daneben (gespeicherte Schemas, eigene Paletten und Pakete, letzte
Einstellungen) bleibt, wie er ist – nicht löschen.

Das Programm zeigt selbst einen Hinweis, wenn es eine neuere Version gibt.

## Tool Launcher

Bequemer geht es mit dem
[Tool Launcher](https://github.com/Marcel1853/tool-launcher): Er installiert,
aktualisiert und startet das Programm vom USB-Stick aus.
